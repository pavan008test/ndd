

Need to install the two debs libhavege1_1.9.1-3_arm64.deb and haveged_1.9.1-3_arm64.deb in sequnce

1. Install libhavege1_1.9.1-3_arm64.deb first using following command
   sudo dpkg -i libhavege1_1.9.1-3_arm64.deb

2. Then install haveged_1.9.1-3_arm64.deb using following command
   sudo dpkg -i haveged_1.9.1-3_arm64.deb
